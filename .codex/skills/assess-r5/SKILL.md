2. **写 6 段指数区间**（每段 9 步硬流程）

## 第 1 批硬流程

[A] 算总段数 = 6 + 10N + 2^(N+1)
[B] **Write** `books/<书名>/<章节号>/role-5-output.md`（骨架文件，120 个占位符齐全；以后只能 Edit，不能 Write）
[C] **Write** `books/<书名>/<章节号>/role-5-progress.md`（所有占位符列表 + 进度状态）
[D] 写 6 段指数区间，每段走 9 步硬流程：
    - [1] 写正文（每段 2 句话，第一句固定句式，第二句 1 个句号 + 一个生活瞬间）
    - [2] W1-W21 自检
    - [3] 书内引用核验（如有）
    - [4] collocation_check（如有可疑搭配）
    - [5] 反偷懒 / 反过度自信 / 反无中生有
    - [5.5] **禁用词总闸 grep 两轮（必跑）**：
      ```bash
      # 第一轮通用
      echo "[正文]" | grep -nE "而是|而不是|但是|然而|不过|不仅|同时|另外|此外|反而|可是|虽然|真的|确实|其实|可以说|某种程度上|卡|松了|崩|炸|拉扯|稳住|接住|长出来|被激活|顺起来|接上|做熟|方法感|先抓|——"
      # 第二轮领域（按 domain-pack §3 拼）
      echo "[正文]" | grep -nE "[领域禁用词]"
      ```
      两轮都 0 命中才能 Edit
    - [6] Edit 替换 `<!-- PH-INDEX-XX -->` 占位符
    - [7] Read 核验（占位符已替换、文件未被截断）
    - [8] Edit progress.md 单行勾选 ✅

## 关键约束

- ❌ 骨架建立后**永不 Write 整个 role-5-output.md**——只能 Edit
- ❌ progress.md 永远只 Edit 单行从 `[ ]` 改 `[x]`，禁止追加新块
- ❌ 不要主动写维度版或画像
- ✅ 6 段区间之间梯度差异要可感知（1-2 档"往往" / 3-4 档"中间感" / 5-6 档"还在摸索"）
