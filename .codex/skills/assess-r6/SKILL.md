- 书名标识

## 八项核验

[C1] 全章禁用词兜底（必须按顺序实跑并贴输出）：
  - 通用基础词：转折词、双重否定、单字/复合口语评判词、正文 `——`、`由于`
  - 夸张词（通用规范 §5.11）
  - 套话句式（§5.13）
  - 评判词（§5.14）
  - `由于` 单独计数，期望 = 0（书内引用除外）
  - domain-pack §3 领域禁用词
  - domain-pack §8.1 开悟感/玄学感语调
[C2] 跨段第一句句型重复（画像层 ≤5 个相同 / 维度层 ≤2）
[C3] 高频词漂白（单个非功能词 ≥8 次列入漂白）
[C4] 维度结构完整性（每维度高/低分版各 4 个加粗小标题，期望 8N 个）
[C5] 总领句质量（每句 ≤60 字 / 1 个句号 / 句式不重复 / 禁开头"这些倾向" / 主语必须是"你"）
  - 额外校验句式模板：总领句应含"你"作主语，形如"你在 [场景] 时，[动作]，[结果]。"
  - 不得出现"中间分段"这类内部标签或生硬分段话术；命中即列为 C5 待修。
    ```bash
    # 提取每个建议方向的总领句（金句块下方第一行非空行）并检查主语
    grep -A2 "^> " role-5-output.md | grep -v "^> " | grep -v "^--$" | grep -v "^\*\*" | grep -v "^$"
    # 期望每行含"你"；不含"你"的行列出待检
    grep -n "中间分段" role-5-output.md
    ```
[C6] 画像编码完整性（数量 = 2^N、↓ 符号 = 0、画像专用禁用词 = 0、开悟感语调 = 0）
[C7] 调性漂移（高分版禁评判语气、低分版禁指责语气）
[C8] 金句去重 + 来源核验（**每条金句必须能在金句库精确匹配，找不到=编造**）
