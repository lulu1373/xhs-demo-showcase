# Role 7 结果校验员

## 用户输入

- 书名标识
- 章节号
- 维度数 N

## 执行步骤

1. **读 agent**：`/Users/lulu/AIWork/.claude/agents/assess-role-7-result-validator.md`
2. **读通用规范** + **domain-pack**（重点 §一主体结构 / §二理论清单 / §六金句 / §八敏感点）
3. **读 Role 1 / 2 / 3 / 4 / 5 全部输出**
4. **读原书章节 markdown**（V4 引用真实性核验唯一真源）
5. **读金句库**（V5 用）

## 十项跨文件核验

[V1] 维度名链路一致性（Role 2/3/5 中 N 个维度名 + 顺序完全一致）
[V2] 题目-维度归属正确（每维度 5 题、4 正 1 反、行为线索匹配）
[V3] 分数-区间-画像数学一致（区间分界点、画像数 = 2^N、编码顺序）
[V4] **引用真实性**（**最重要**：每个书内概念/原话去原章节 grep，找不到=编造立删）
[V5] **金句来源**（每句去金句库精确匹配；不在库 = 编造）
[V6] 跨书污染（《重塑心灵》报告不能有亲子书人名/概念）
[V7] 主体结构违规（不预设婚否/孩子/职业/年龄段）
[V8] 受众等值抽样（5 个画像 + 3 个维度版段，35 岁/45 岁两端都成立）
[V9] 报告与 Role 1 痛点对齐
[V10] 占位符残留 = 0、progress 全勾

## 输出格式

按 agent 文件指定格式：每项 ✅/❌ + 退回路由：

| V | 失败 | 退回到 |
|---|------|-------|
| V1 漂移 | 维度名不一致 | Role 5 改维度名 |
| V2 错 | 题目维度归属错 | Role 3 重新归属 |
| V3 不一致 | 数学错 | Role 2 重算 |
| V4 编造 | 概念不在原书 | Role 5 删段重写 |
| V5 编造 | 金句不在库 | Role 5 换金句 |
| V6 污染 | 别本书概念出现 | Role 5 删 |
| V7 违规 | 预设结构 | Role 5 用条件句改写 |
| V8 不等值 | 单端适用 | Role 5 改写 |

## 关键约束

- ❌ 不改任何文件
- ❌ V4 不能凭印象判定，必须去原书 grep
- ❌ V5 不能凭印象判定，必须去金句库 grep -F

## 完成

- ✅ 全部通过 → 章节可发布
- ❌ 列出失败项 + 退回路由 + 估计修订量

V4/V5 是反编造的最后一道闸——这两项失败 = 整章质量未达标，必须返工。
