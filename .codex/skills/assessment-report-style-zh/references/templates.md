# Templates

Use these as structural templates, not rigid fill-in-the-blank scripts.

## Template A: Dimension report

Use for high / medium / low style feedback.

```md
## 维度名

你在【维度名】维度的得分为：高 / 中 / 低水平

### 为何要重视
说明这个维度为什么重要，它影响什么。

### 你当前的状态
描述这种水平在日常互动中的具体表现。

### 可能的原因 / 积极影响 / 潜在风险
根据高、中、低不同水平，写积极影响或风险，必要时补原因。

### 成长建议
- 一个低门槛动作
- 一个能重复练习的动作
```

## Template B: Combination archetype report

Use for multi-axis combination results.

```md
# 类型名

副标题 / 一句话标签

## 你的核心模式
写出组合结果是什么，以及它在生活中的主表现。

## 深层信念 / 内在逻辑
解释这种模式背后的信念、需求、保护策略或适应方式。

## 隐含追求 / 潜在心理课题
说明这种模式其实在追求什么，或者绕开什么。

## 需要留意的风险
写 2-3 个最可能的代价或循环。

## 可以先做的改变
- 建议 1
- 建议 2
```

## Template C: Long-form developmental narrative

Use for family-of-origin or life-pattern reports.

```md
# 结果标题

## 你经历了怎样的环境
写环境体验和家庭气候，不急着解释理论。

## 这种环境如何影响了你
分成自我层面和关系层面，解释形成的模式。

## 你可能带着怎样的深层需求或誓言
点出反复出现的需求、信念、保护壳、内在誓言。

## 你会如何继续创造关系 / 家庭 / 生活
把过去和未来连接起来，指出可能的延续与修正空间。

## 此刻最有价值的下一步
给一两个温和但具体的行动方向。
```

## Template D: Theory-backed dimension interpretation

Use when the user wants a more explanatory report like `教养智慧指数评估_报告内容.md`.

```md
## 维度名

### 高 / 中 / 低
先用生活化语言描述这个水平。

### 这种能力的核心 / 为什么会这样
给出理论上可理解的解释，但要落回到用户生活。

### 对关系或发展的实际影响
说清楚后果，不夸张。

### 建议
给两个能立刻尝试的动作。
```

## Template selection hints

- If the report is driven by score levels per dimension, use Template A or D.
- If the report is driven by type combinations and persona naming, use Template B.
- If the report is driven by developmental experience and relational reproduction, use Template C.
