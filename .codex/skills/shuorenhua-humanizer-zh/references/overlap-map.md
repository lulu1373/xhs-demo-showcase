# Overlap Map

本文件只做“问题家族对齐”，帮助合并 skill 在执行时去重。原则：同一家族只改一次，不重复抛光。

| 合并问题家族 | `shuorenhua` 侧重点 | `humanizer-zh` 对应模式 | 合并后的处理原则 |
| --- | --- | --- | --- |
| 开场套话 / 协作交流痕迹 | 开场套话、谄媚句、元评论 | 19, 21, 22 | 删除姿态层，直接进入事实或判断 |
| 总结式收尾 / 空泛正向结论 | 总结腔、空收尾 | 24 | 删空结论，换成具体动作、事实或留白 |
| 无源引用 / 模糊归因 | 无源引用、占位式权威 | 5, 20 | 不补假来源；按场景选择删、标注缺来源或保留占位 |
| 宣传腔 / 重要性夸大 | 商业黑话、表演感、故作洞见 | 1, 4, 7 | 降调，去宏大意义，改回可验证事实 |
| 工程师腔 / narrator 腔 / 虚假深度 | 表演性技术腔、解释层 | 3 | 去“解释自己在解释”的层，回到动作和信息 |
| 二元对比 / 否定式排比 | 不是 X，而是 Y | 9 | 多数删前半句，直接说真正要表达的 Y |
| 三段式堆砌 | 模板化列举 | 10 | 打散成 2 项、4 项或连续叙述 |
| 填充词 / 连接词过多 | 翻译腔、提示层 | 22, 快速检查清单 | 能删就删，保留最必要的一项 |
| 系动词回避 / 刻意抽象化 | 翻译腔、动作虚化 | 8 | 能直接用“是 / 有 / 做了”就不用绕写 |
| 同义词循环 / 词汇表演 | 口癖和堆词 | 11 | 收敛回稳定指称，不机械变着花样换词 |
| 虚假范围 / 宏大叙述 | 空泛洞见、世界观式抬高 | 12 | 改成真实边界内的范围与对象 |
| 破折号 / 粗体 / inline 标题 / emoji | 风格装饰过量 | 13, 14, 15, 17 | 默认减到最低，只保留必要格式 |
| 标题大小写 / 引号等格式残留 | 中英混排格式问题 | 16, 18 | 仅在确实影响中文阅读时处理 |
| 过度限定 | 含糊其辞、姿态过重 | 23 | 压回清楚但不过度夸张的陈述 |

## Priority rule

- 中文语域、误杀边界、场景限制：优先 `shuorenhua`
- 结构模板、句法病灶、格式病灶：优先 `humanizer-zh`
- 同时命中时，选更具体的标签，只做一次修改

## Stop condition

出现下面任一情况就停止继续“去味”：

- 再改会损伤事实、术语或责任主体
- 再改只是在做同义词抛光，没有新增信息价值
- `docs`、`status` 场景已经达到“可直接发”
