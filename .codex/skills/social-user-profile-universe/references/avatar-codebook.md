# Avatar Codebook

头像层只用于“自我呈现方式”分析，不能直接输出确定的性别、年龄、人格结论。所有判断都应写成群体倾向、平台呈现或低置信度线索。

## A. Avatar Type Codes

### A1 真人/本人照片类

常见子类：

- 清晰正面生活照
- 精修自拍/氛围感自拍
- 职业形象照
- 侧脸/背影/墨镜/贴纸遮挡
- 局部特写

可解释为更愿意用真实形象参与社交，或强调自信、专业、氛围、边界感。不要直接断言真实性别年龄。

### A2 风景/花草/自然静物类

常见子类：

- 山水、日出日落、云海、荷花
- 大海、星空、草原
- 极简冷调风景
- 局部花草特写

可解释为审美退隐、情绪安放、低暴露社交、宁静/自由/文艺取向。

### A3 抽象艺术/静物审美类

常见子类：

- 抽象画
- 色块/几何
- 小众摄影
- 纯黑/纯白/空白

可解释为审美化、边界感、低暴露、神秘感或情绪状态呈现。纯黑/空白不要直接写成抑郁。

### A4 卡通/动漫/二次元类

常见子类：

- 萌系卡通
- 经典动漫角色
- 热血/暗黑角色
- 迪士尼/热门 IP

可解释为符号化身份、兴趣圈层、年轻化表达、理想自我投射。

### A5 萌宠/动物类

常见子类：

- 自家猫狗
- 软萌动物
- 猛兽/雄鹰/狼
- 小众动物

可解释为情感寄托、陪伴感、力量感或小众审美。不要把动物特征直接套到人格上。

### A6 明星/网红/网图类

常见子类：

- 明星偶像
- 网红照片
- 俊男美女网图
- 无辨识度美图

可解释为理想形象投射、审美认同、社交形象管理或粉丝身份。

### A7 家人/孩子/情侣合照类

常见子类：

- 孩子单人照
- 亲子合照
- 全家福
- 情侣合照
- 父母/家人合照

可解释为家庭身份呈现、亲密关系公开、关系价值优先。涉及孩子时注意隐私和未成年人边界。

### A8 插画/符号/搞怪梗图类

常见子类：

- 插画头像
- 表情包
- 沙雕梗图
- slogan/文字图
- logo/符号

可解释为梗化表达、幽默社交、符号化身份、圈层暗号或观点展示。

### A9 系统默认/无法识别类

包括系统默认头像、加载失败、过小、遮挡严重、无法判断。

标注为“不足以判断”，不要补推。

## P. Presentation Mode Codes

- `P1 真实自我呈现`: 用本人照片、生活照、职业照等直接呈现自己。
- `P2 家庭身份呈现`: 用孩子、伴侣、全家福、亲子照呈现关系身份。
- `P3 关系/价值立场呈现`: 用情侣、偶像、口号、价值符号表达认同。
- `P4 审美退隐呈现`: 用风景、花草、静物、抽象图降低个人暴露。
- `P5 职业/专业呈现`: 用职业形象照、行业符号、机构标识呈现专业身份。
- `P6 符号化/梗化呈现`: 用卡通、IP、表情包、梗图、符号表达社交角色。

## Link Avatar To Comment

输出时用三段式，不做直接人格判断：

```text
该用户头像属于 A*，更像 P* 自我呈现；
在评论中主要表现为 E* 表达风格；
在该议题里更常扮演 X 互动角色。
```

示例：

```text
头像是风景/自然静物类，更像审美退隐呈现；评论多用分析论证型表达，在“孩子”议题中主要扮演现实成本派。
```

## Avoid

- “头像说明这个人一定是女性/中年/内向/缺爱。”
- “用孩子头像就是幸福感强。”
- “纯黑头像就是情绪低谷。”
- “动漫头像就是幼稚。”

替代写法：

- “更倾向于用家庭身份参与平台呈现。”
- “在该账号的公开形象中，个人真实面孔被弱化。”
- “头像提供的是呈现线索，评论内容才是角色判断主证据。”

## Full-Scale Avatar Layer

头像层不要长期停留在 40 个样本。按交付风险分三档：

- `sample_manual`: 40-100 个头像，人工标注，用于验证头像码本和链路是否可用。
- `review_sample`: 200-500 个头像，按高赞、画像类型、一级/二级评论、强度分层抽样，适合方向判断。
- `full_auto`: 对全量唯一头像 URL 自动视觉分类，再抽样人工复核，适合看板趋势展示。

全量自动分类建议流程：

```text
全量头像 URL
  -> 去重
  -> 下载/缓存头像
  -> 自动视觉分类 A1-A9 / P1-P6
  -> 保留已有人工标注作为金标覆盖
  -> 抽样生成 contact sheet 复核
  -> 输出全量头像分布 + 置信度 + 复核命中率
  -> 回填评论层和用户层
```

本项目已试过的 `clip_v2` 口径：

- 对 `6323` 个小红书唯一头像 URL 跑 OpenCLIP ViT-B-32 零样本分类。
- 保留 `manual_40` 中能对齐的人工标注作为金标覆盖。
- 输出 `xhs_v31_avatar_clip_v2_full.csv`、`xhs_v31_comment_layer_avatar_clip_v2.csv`、`xhs_v31_avatar_clip_v2_summary.json`、`xhs_v31_avatar_clip_v2_audit_contact_sheet.jpg`。
- 结论只能写“趋势参考”，因为头像类别含主观边界，且明星/网图、真人照片、动漫/插画之间仍会有撞类。

看板脚注必须说明：

```text
头像层使用 N 个唯一头像 URL 的自动分类，结果用于趋势参考，不作为个体人格判断。
```
