# Persona Naming Guide

这个文件用于把底层画像宇宙里的 `D/S/H/M` 码和技术型 persona，翻译成汇报页上更好懂的人群名称。

原则：底层分类保持稳定，对外名称面向业务读者。表格里两者都保留。

```text
internal_persona_code = 稳定分析码，便于跨帖复用
persona_display_name = 汇报页画像名，便于人一眼看懂
```

## 1. Naming Formula

优先使用：

```text
核心关注/痛点 + 行为倾向/心理任务 + 人群身份
```

示例：

- `关系沟通修复型家长`
- `情绪学业高压型家长`
- `自主成长塑形型家长`
- `代际创伤反思型家长`

如果不是亲子议题，把身份后缀换成：

- `型用户`
- `型讨论者`
- `型妈妈/爸爸`
- `型学生`
- `型照护者`
- `型从业者`

## 2. Avoid Abstract Labels In Dashboards

这些底层名适合表格和规则，不适合直接做大标题：

- `反投射者`
- `边界维护者`
- `创伤识别者`
- `现实成本派`
- `结构条件派`
- `操作处置派`
- `轻互动者`
- `校正少数派`

对外展示时改成：

- `反投射者` -> `关系动机拆解型用户` / `他人动机警觉型用户`
- `边界维护者` -> `自主边界守护型用户`
- `创伤识别者` -> `家庭创伤反思型用户`
- `现实成本派` -> `现实压力核算型用户`
- `责任规训派` -> `规则责任守护型用户`
- `专家鉴伪者` -> `专业真实性鉴别型用户`
- `健康联结者` -> `健康关系建设型用户`
- `结构条件派` -> `结构条件解释型用户`
- `操作处置派` -> `方法路径求解型用户`
- `轻互动者` -> `轻共鸣互动型用户`
- `校正少数派` -> `经验校正补充型用户`

## 3. Parent Topic Naming Bank

亲子/孩子/家长议题优先使用下面这组更直观的名字。

先按平台选择命名口径：

- 小红书单帖、家庭关系议题：用 `XHS Display Personas`。
- 知乎“孩子”跨问题池：用 `Zhihu Display Personas`。
- 通用亲子/家长报告：可用后面的 `Parent Topic Naming Bank`。

## 3A. XHS Display Personas

适用于小红书单帖家庭关系/亲子关系评论区。小红书通常轻互动和平台表情更多，且头像层可能只有部分人工标注。

### 轻共鸣接梗型讨论者

底层常见组合：`轻互动者`，常见分支 `S6/M4/未细分`。

核心解释：主要用短反应、接梗、附和和情绪符号参与讨论，是评论区声量最大的回声层。

常见关注问题：

- 接梗附和
- 快速表态
- 平台语气
- 轻量共鸣

### 专业真实性鉴别型讨论者

底层常见组合：`专家鉴伪者`，常见分支 `S5`。

核心解释：最在意谁是真专家、真患者、真懂行，常用一句话给专业性和权威感定价。

常见关注问题：

- 专家与患者
- 专业真假
- 方法是否有用
- 权威可信度

### 自主边界守护型讨论者

底层常见组合：`边界维护者 + 健康联结者 + 校正少数派`，常见分支 `S2/S7/S4c`。

核心解释：把讨论拉回边界、尊重和具体情境，关注少管、放手、健康联结和不要一概而论。

常见关注问题：

- 自主与边界
- 尊重选择
- 健康关系
- 反泛化

### 问题解决与成因拆解型讨论者

底层常见组合：`操作处置派 + 结构条件派 + 创伤识别者 + 反投射者 + 现实成本派 + 责任规训派`。

核心解释：更愿意解释问题从哪里来、现实代价是什么，以及下一步怎么处理。

常见关注问题：

- 创伤与控制
- 现实成本
- 结构条件
- 方法路径

## 3B. Zhihu Display Personas

适用于知乎“孩子”关键词跨问题评论池。知乎通常不是单帖评论区，而是多个问题标题下的评论集合，优先展示议题触发，不默认展示头像层。

### 心理创伤识别型讨论者

底层常见组合：`创伤识别者`，常见分支 `S3`。

核心解释：最常把孩子问题理解为家庭失衡、依恋创伤、控制关系或长期忽视的外显症状。

常见关注问题：

- 抑郁焦虑
- 原生家庭
- 安全感
- 控制与伤害

### 情绪立场共鸣型讨论者

底层常见组合：`立场共鸣者`，常见分支 `S6`。

核心解释：先站队、先表态，把个案里的委屈、愤怒、心疼或认同快速放大成评论区气压。

常见关注问题：

- 情绪支持
- 价值表态
- 共情声援
- 经验认同

### 现实边界规训型讨论者

底层常见组合：`现实成本派 + 边界规训派 + 校正少数派`，常见分支 `S4a/S2/S4b/S4c`。

核心解释：关注养育成本、婚育代价、家庭责任、规则边界和不要把个案推成绝对结论。

常见关注问题：

- 现实成本
- 责任规则
- 家庭边界
- 反泛化

### 方法结构求解型讨论者

底层常见组合：`操作处置派 + 结构条件派`，常见分支 `H1-H5/S8a-S8d`。

核心解释：更愿意把讨论推进到怎么办，或把个人困境放回学校制度、资源阶层和性别分工里解释。

常见关注问题：

- 就医休学
- 育儿沟通
- 学校制度
- 资源条件

## 3C. Generic Parent Topic Naming Bank

亲子/孩子/家长议题在没有明确平台模板时，可使用下面这组更直观的名字。

### 关系沟通修复型家长

底层常见组合：`S2 边界维护` + `S7 健康联结` + `H3 育儿操作`，有时伴随 `S4c 泛化校正`。

核心解释：最怕关系慢慢耗坏，关注孩子不说、父母不会说，以及青春期沟通里的疏离和误解。

常见关注问题：

- 沟通断裂
- 信任与尊重
- 安全感与依恋
- 自主成长与独立
- 青春期与叛逆

### 情绪学业高压型家长

底层常见组合：`S3 创伤识别` + `S4a 成本现实` + `H4 学业应对` + `H3 育儿操作`。

核心解释：矛盾最容易在情绪失控、医学作业、返校困难、校园适应问题上集中爆发。

常见关注问题：

- 学习压力与厌学
- 情绪管理
- 校园适应与被欺负
- 自主成长与独立
- 沟通断裂

### 自主成长塑形型家长

底层常见组合：`S2 边界维护` + `S7 健康联结` + `H3 育儿操作` + `H5 资源配置`。

核心解释：关注的不只是当下是否听话，更是孩子的独立性、自驱力、边界感和长期责任感。

常见关注问题：

- 自主成长与独立
- 信任与尊重
- 控制与放手
- 规则与管教
- 学习压力与厌学

### 代际创伤反思型家长

底层常见组合：`S3 创伤识别` + `S8c 性别分工` + `S8b 资源阶层` + `S7 健康联结`。

核心解释：讨论不只停留在孩子身上，而是不断回看原生家庭、老人越位、家庭失衡和父母自己的伤。

常见关注问题：

- 父母自我成长
- 原生家庭创伤
- 安全感与依恋
- 自主成长与独立
- 家庭系统失衡

### 规则责任守护型家长

底层常见组合：`S4b 责任规则` + `H3 育儿操作` + `H4 学业应对`。

核心解释：重点在规矩、边界、责任和后果，担心孩子失序、越界或缺少基本社会规则。

常见关注问题：

- 规则与管教
- 责任意识
- 学业应对
- 手机/网络边界
- 家校协同

### 现实资源核算型家长

底层常见组合：`S4a 成本现实` + `H5 资源配置` + `S8b 资源阶层`。

核心解释：关注养育的真实成本，包括时间、金钱、陪伴、教育资源和家庭分工。

常见关注问题：

- 时间精力分配
- 教育投入
- 照护资源
- 家庭分工
- 经济压力

### 专业方法求证型家长

底层常见组合：`S5 专家鉴伪` + `H2 医疗转介` + `H3 育儿操作` + `H4 学业应对`。

核心解释：更在意建议是否专业、方法是否靠谱、医生/老师/博主是否真的懂。

常见关注问题：

- 科普解读
- 医疗/心理转介
- 教育方法
- 专业真假辨别
- 干预路径

## 4. Naming By Distribution

当一类用户不是单一分支，而是多个分支混合时，用主分支决定前半句，用次分支补后半句。

示例：

- `S3` 主、`H4` 次：`情绪学业高压型家长`
- `S2` 主、`S7` 次：`关系沟通修复型家长`
- `S4a` 主、`H5` 次：`现实资源核算型家长`
- `S3` 主、`S8c` 次：`代际创伤反思型家长`
- `H3` 主、`S5` 次：`专业方法求证型家长`

如果用户群体高度混合，不要硬起一个漂亮名字。先拆成两个群体，或标为：

```text
双重关注型家长：情绪压力 + 关系修复
```

## 5. Dashboard Copy Pattern

画像卡片建议固定为：

```text
画像 A
关系沟通修复型家长
最怕关系慢慢耗坏，核心困扰是孩子不说、父母不会说，以及青春期里的疏离和误解。
```

不要写成：

```text
画像 A
边界维护者 + 健康联结者
S2/S7/H3 混合人群
```

底层码可以放在小字或表格字段里。

## 6. Output Fields

建议同时输出：

- `internal_persona_code`: 如 `S2+S7+H3`
- `internal_persona_label`: 如 `边界维护者 / 健康联结者 / 操作处置派`
- `persona_display_name`: 如 `关系沟通修复型家长`
- `persona_short_name`: 如 `关系修复型`
- `persona_explanation`: 一句话解释这个群体最关心什么
