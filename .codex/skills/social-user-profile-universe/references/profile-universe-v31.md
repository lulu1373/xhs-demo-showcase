# Profile Universe V3.1

本文件是“社交评论 + 可选头像”的用户画像宇宙完整码本。目标是跨帖子、跨议题稳定复用，而不是为单个帖子临时造类。

## 0. Core Principle

分析顺序固定为：

```text
评论文本主功能 -> 议题域 D -> 分支 S/H/M -> 单条评论角色 L1
  -> 用户聚合 L2 -> 议题触发 L3 -> 头像自我呈现 L4
```

不要用头像直接推人格。头像只提供“自我呈现方式”，需要与评论表达和聚合行为互证。

## 1. Layers

### L1 单条评论角色层

单条评论只说明该用户在这一条评论里的发声功能，例如“反投射”“创伤识别”“现实成本”“轻互动”。不要把 L1 写成稳定用户身份。

### L2 用户聚合层

同一用户多条评论聚合后，才输出：

- `primary_persona`: 主画像
- `secondary_persona`: 次画像
- `role_stability`: 角色稳定性
- `intensity`: 表达强度
- `representative_comments`: 代表评论

### L3 议题触发层

记录用户是否因不同帖子标题、议题关键词、评论上下文而切换角色。跨议题稳定复用时，这层很重要。

### L4 头像自我呈现层

头像只回答“这个账号如何呈现自己”，不回答“这个人真实是什么人格”。头像可参与解释链路：

```text
头像风格 -> 自我呈现方式 -> 评论表达风格 -> 议题立场与互动角色
```

## 2. Domain Codes

### D1 关系-心理域

评论主要解释个体心理、关系边界、投射、创伤、成本、责任、规则、真假专家、健康联结等。

适合：

- 亲密关系、亲子关系、原生家庭、控制感、创伤、不安全感
- “关你什么事/关我什么事”式边界维护
- “她是在拉人下水/自证正确”式投射识别
- 对现实成本、责任规则、专家真实性的判断

### D2 结构-制度域

评论主要解释制度、组织、平台、学校、阶层、资源、性别分工、城市压力等结构条件。

适合：

- 学校/机构/平台/组织责任
- 资源、阶层、教育资本
- 母职惩罚、父职缺位、生育负担
- 城市高压、环境异化、系统性困境

### D3 实务-程序域

评论主要给出具体处理路径、行动建议、法律/医疗/育儿/学业/资源操作。

D3 必须有明确“怎么做”。只有情绪判断或泛泛建议不进 D3。

### D4 轻互动-元评论域

评论主功能是附和、元评论、偏题纠错、玩梗、轻量互动。

D4 要收窄：长评论、含实质论证的评论，不因为开头有“我也是/太对了”就进 D4。

## 3. D1 Branches

### S1 反投射派

核心识别：认为对方在投射、拉人下水、自我合理化、自证正确、把自己的处境包装成普遍真理。

典型信号：

- “她只是想证明自己没错”
- “这是想把别人也拉下水”
- “自己过不好就见不得别人好”
- “投射/代入/自我感动/自我洗脑”

边界：如果重点是现实成本，不是动机投射，进 S4a。

### S2 边界维护派

核心识别：强调个人选择、边界、别管别人、尊重差异。

典型信号：

- “关你什么事”
- “别人怎么选是别人的自由”
- “别替别人做决定”
- “不想生/想生都可以”

边界：如果不仅维护边界，还指出结构压迫，可能进 D2。

### S3 创伤识别派

核心识别：用创伤、原生家庭、控制、匮乏、不安全感等心理机制解释行为。

典型信号：

- “这是原生家庭创伤”
- “控制欲/缺爱/不安全感”
- “小时候没有被好好对待”
- “把伤害复制给下一代”

边界：如果重点是学校、制度、组织造成伤害，进 S8a；如果给出治疗/就医路径，进 H2。

### S4a 成本现实型

核心识别：强调现实成本、生活压力、婚育负担、养育成本、时间精力、经济账。

典型信号：

- “养孩子成本太高”
- “时间、钱、精力都不够”
- “婚姻/生育/育儿压力”
- “现实不是一句爱就能解决”

边界：如果重点是反泛化和纠正夸张说法，进 S4c。

### S4b 责任规则型

核心识别：强调责任、规矩、未成年人边界、家长义务、纪律、社会规范。

典型信号：

- “家长要负责”
- “未成年人不能这样”
- “规矩就是规矩”
- “该管就得管”

边界：如果提出法律流程，进 H1。

### S4c 泛化校正型

核心识别：反对一概而论，补充条件、概率、例外、语义校正。

典型信号：

- “不能一棒子打死”
- “不是所有人都这样”
- “要看具体情况”
- “这个说法太绝对”

边界：如果校正的是主题、定义、跑题，且不展开实质观点，进 M3。

### S5 专家鉴伪派

核心识别：判断谁是真专家、真患者、真经历、真懂行，质疑专业身份或经验真实性。

典型信号：

- “这人不像专业的”
- “真正的医生/老师/患者不会这么说”
- “一看就是编的/营销号”
- “有经验的人都知道”

边界：小红书里玩梗若服务于“专家/患者真实性判断”，仍进 S5，不进 M4。

### S6 情绪站队派

核心识别：主要是情绪共鸣、立场放大、支持/反对，无明显机制、结构或操作路径。

典型信号：

- “太对了”
- “狠狠共情”
- “支持/反对”
- “看得我气死了”

边界：S6 不是垃圾桶。能归到更具体分支时，优先具体分支。

### S7 健康联结派

核心识别：强调健康的爱、稳定关系、自愿连接、尊重和共同成长。

典型信号：

- “好的关系应该是互相滋养”
- “爱不是控制”
- “自愿、尊重、边界”
- “健康家庭/健康亲密关系”

## 4. D2 Branches

### S8a 制度约束型

学校、组织、平台、法律制度、管理机制、公共系统造成的约束或责任。

### S8b 资源阶层型

资源差异、阶层差异、教育资本、家庭资本、经济机会对人的影响。

### S8c 性别分工型

母职/父职、生育责任、婚育结构、家务分工、性别期待。

### S8d 环境异化型

城市压力、工作制度、高压环境、平台机制、社会氛围对人的异化。

## 5. D3 Branches

### H1 法律程序型

报警、起诉、证据、监护权、合同、维权、平台申诉、法律路径。

### H2 医疗转介型

就医、心理咨询、精神科、诊断建议、药物、医院/医生转介。

不要把它写成诊断，只标注评论在建议医疗转介。

### H3 育儿操作型

如何沟通、陪伴、立规矩、处理孩子情绪、亲子互动的具体方法。

### H4 学业应对型

学校、考试、作业、升学、学习策略、老师沟通、校园应对。

### H5 资源配置型

钱、时间、照护、课程、服务、社群、家庭分工等资源如何配置。

## 6. D4 Branches

### M1 纯附和共鸣型

只表达“同意、共情、抱抱、我也是”，没有新增判断。

### M2 元评论评价型

评价帖子、评论区、作者表达方式、平台氛围，而不是讨论主议题本身。

### M3 偏题纠错型

指出跑题、定义错、对象错、事实错，但不展开成实质分析。

### M4 轻梗玩笑型

玩梗、沙雕、反讽、表情包式互动，主功能是气氛，不是论证。

## 7. Persona Labels

Persona 分两层：

- `internal_persona_label`: 稳定分析名，适合规则、复核、跨帖对齐。
- `persona_display_name`: 对外展示名，适合看板、汇报、画像卡片。

对外展示名必须参考 [persona-naming-guide.md](./persona-naming-guide.md)。不要直接把“某某派/某某者”作为看板主标题。

### XHS Compatible Internal Personas

- `反投射者`: 高频 S1，擅长识别“拉下水/投射/自证正确”。展示名可写 `关系动机拆解型用户`。
- `边界维护者`: 高频 S2，强调个人选择和边界。展示名可写 `自主边界守护型用户`。
- `创伤识别者`: 高频 S3，常用创伤/原生家庭解释。展示名可写 `家庭创伤反思型用户`。
- `现实成本派`: 高频 S4a，关注现实负担。展示名可写 `现实压力核算型用户`。
- `责任规训派`: 高频 S4b，强调规则、责任、纪律。展示名可写 `规则责任守护型用户`。
- `专家鉴伪者`: 高频 S5，判断真假专家、真假经验。展示名可写 `专业真实性鉴别型用户`。
- `健康联结者`: 高频 S7，强调健康关系。展示名可写 `健康关系建设型用户`。
- `结构条件派`: 高频 D2/S8，解释制度与结构。展示名可写 `结构条件解释型用户`。
- `操作处置派`: 高频 D3/H，给路径和方法。展示名可写 `方法路径求解型用户`。
- `轻互动者`: 高频 D4/M，互动为主。展示名可写 `轻共鸣互动型用户`。
- `校正少数派`: 高频 S4c 或 M3，纠偏、补条件、反泛化。展示名可写 `经验校正补充型用户`。

### Zhihu Compatible Internal Personas

- `创伤识别者`
- `立场共鸣者`
- `现实成本派`
- `结构条件派`
- `操作处置派`
- `边界规训派`
- `校正少数派`

### Parent Topic Display Personas

亲子/孩子/家长议题优先使用更直观的 display persona：

- `关系沟通修复型家长`: 常见组合 `S2+S7+H3`，关注沟通断裂、信任与尊重、安全感、自主成长。
- `情绪学业高压型家长`: 常见组合 `S3+S4a+H4`，关注情绪管理、学业压力、校园适应、厌学返校。
- `自主成长塑形型家长`: 常见组合 `S2+S7+H3+H5`，关注独立性、自驱力、边界感、规则与放手。
- `代际创伤反思型家长`: 常见组合 `S3+S8c+S8b+S7`，关注原生家庭、代际关系、家庭系统失衡。
- `规则责任守护型家长`: 常见组合 `S4b+H3+H4`，关注规矩、责任、纪律、后果和家校协同。
- `现实资源核算型家长`: 常见组合 `S4a+H5+S8b`，关注时间、金钱、照护、教育资源和家庭分工。
- `专业方法求证型家长`: 常见组合 `S5+H2+H3+H4`，关注专业真假、方法可靠性、转介和干预路径。

生成看板时，优先展示这些名字；底层 `D/S/H/M` 只作为解释字段或复核字段。

### Platform Display Personas

平台看板优先使用平台专属展示名，不要把小红书和知乎混用。

小红书家庭关系议题常用 4 类：

- `轻共鸣接梗型讨论者`: 底层 `轻互动者`，小红书表情、接梗、附和声量高。
- `专业真实性鉴别型讨论者`: 底层 `专家鉴伪者/S5`，判断谁是真专家、真患者、真懂行。
- `自主边界守护型讨论者`: 底层 `边界维护者 + 健康联结者 + 校正少数派`，强调少管、放手、尊重和反泛化。
- `问题解决与成因拆解型讨论者`: 底层 `操作处置派 + 结构条件派 + 创伤识别者 + 反投射者 + 现实成本派 + 责任规训派`。

知乎孩子议题常用 4 类：

- `心理创伤识别型讨论者`: 底层 `创伤识别者/S3`，识别家庭失衡、创伤、控制和安全感问题。
- `情绪立场共鸣型讨论者`: 底层 `立场共鸣者/S6`，先表态、先共情、放大情绪立场。
- `现实边界规训型讨论者`: 底层 `现实成本派 + 边界规训派 + 校正少数派`，关注成本、责任、规则和边界。
- `方法结构求解型讨论者`: 底层 `操作处置派 + 结构条件派`，关注怎么办以及学校、资源、性别分工等结构条件。

知乎跨问题池默认不展示头像风格，除非已有 `avatar_style` 或独立视觉分类结果。小红书头像层按三档处理：

- `sample_manual`: 40-100 个人工样本，只能验证方法。
- `review_sample`: 200-500 个分层样本，适合方向判断。
- `full_auto`: 全量唯一头像 URL 自动分类 + 抽样复核，适合看板趋势展示。

如果只有 40 条人工头像标注，必须在看板注明“头像层为样本，不代表全量”。如果使用 `full_auto`，必须注明“自动分类结果用于趋势参考，不作为个体人格判断”，并保留模型方法、置信度、人工复核或 audit contact sheet。

## 8. Expression Style Codes

- `E1 温和经验型`: 讲经历，语气缓和，少攻击。
- `E2 求助脆弱型`: 暴露困扰、求助、无力感强。
- `E3 自我叙事型`: 以“我/我家/我身边”为主要证据。
- `E4 分析论证型`: 因果、条件、概念、分点论证明显。
- `E5 反讽金句型`: 讽刺、短句、金句化、攻击性或戏谑感。
- `E6 争辩推进型`: 反驳、追问、对线、连续推进。

## 9. Stability Layer

- `单次发声`: 只有 1 条有效评论，不判稳定主型。
- `稳定主型`: 70%+ 评论落在同一 persona 或相邻分支。
- `主型明确，少量切换`: 主型 50%-70%，有少量跨域切换。
- `双角色摇摆`: 两个 persona 接近，且都超过 30%。
- `多角色切换`: 3 个以上 persona 明显出现，或跨议题强切换。

## 10. Intensity Layer

- `低`: 短句、弱情绪、少判断，更多是补充或附和。
- `中`: 有明确立场或经验，但攻击性、绝对化不强。
- `高`: 强情绪、强判断、反复强调、攻击/控诉/强规训明显。

强度不是价值判断，只描述表达能量。

## 11. Collision Boundaries

- `S4a` vs `S4c`: 成本核算进 S4a；反泛化、补条件、纠正绝对化进 S4c。
- `S3` vs `S8a`: 心理伤害机制进 S3；学校/制度/组织机制进 S8a。
- `D3` vs `D2`: 给行动路径进 D3；解释结构原因进 D2。
- `M3` vs substantive comment: 只做主题/定义/事实纠错进 M3；纠错后展开论证则进对应实质分支。
- `S6` vs concrete D1 branch: 有明确机制、边界、成本、规则、鉴伪时，优先具体分支。
- XHS `S5` vs `M4`: 玩笑服务于专家/患者真实性判断，进 S5。
- XHS `S1` vs `S4a`: “拉下水/自证正确/投射”进 S1；现实账本进 S4a。

## 12. Validation Lessons

V3 first pass 问题：

- D3/D4 容易过度分类。
- 只看开头“我也是/太对了”会误把长实质评论归 D4。
- 没有明确行动路径时，不应归 D3。

V3 second pass 规则：

- D4 收窄，只收主功能为轻互动/元评论/纠错/玩梗。
- D3 要求明确 action path。
- 长评论按主体论证归类。
- 抽样复核后再回改规则，形成 `second_pass`。

人工复核经验：知乎 40 条 D3/D4 复核后，规则收紧可将适配度从约 `12/40` 提升到约 `37/40`。
