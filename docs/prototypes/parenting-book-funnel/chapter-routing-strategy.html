Routing Strategy

书向测评的章节分发方案

技术已确认可以实现自动识别章节，所以这里直接采用单一主方案：用户扫码后自动识别当前章节，并直达本章测评。

自动识别章节 直接进入本章测评
Confirmed Path

自动识别章节，直接进入本章测评

主路径

这是最好的主方案。用户先加企业微信老师，系统如果能识别出当前扫码来自第几章，就直接发送对应章节的小程序测评入口，不让用户自己找章节。

适用场景

新用户/老用户稳定识别当前章节时

方案目标

加上老师后，立刻把用户送到当前章节测评

流程

01

书中第 N 章二维码

用户从具体章节页扫码，进入与老师相关的承接链路。

02

加企业微信老师

第一步统一沉淀到企业微信，先把用户关系建立起来。

03

系统识别当前章节

后台识别这次扫码对应的是第几章，得到当前章节编号。

04

自动发送第 N 章测评

老师侧自动发出对应章节的小程序卡片，不需要用户再去列表里挑选。

05

进入第 N 章测评

用户直接进入当前章节测评，完成测评后继续看结果页和行动建议。

备注

  • 这是体验最顺的主路径。
  • 核心价值是：用户不用自己找章节，扫码后更快进入本章测评；不用添加不同老师的企业微信。
